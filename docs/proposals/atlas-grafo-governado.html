O grafo que se julga sozinho.

O GitKraken te dá os olhos: lanes, curvas, avatares — e você, olhando, encontra a branch que não devia existir, a worktree errada, a obra que nunca voltou à main. Mas quem sabe as regras é você. O Atlas sabe as regras — main-only pétreo, allowlist de worktrees, obra tem que voltar à main — então o grafo do Atlas faz o que nenhum cliente git fará: aponta a violação sozinho. A mesma linguagem visual que você já ama, com a lei pintada por cima. Quieto = saudável. Brilho = violação. Zero palavras necessárias.

A cena: o grafo se desenha como você conhece — lanes, curvas, quem fez o quê. Aí as regras passam por cima: a branch proibida no atlas-server acende em vermelho com o nome da regra pétrea; a obra-12 com 14 commits que nunca voltou à main ganha a etiqueta âmbar de obra parada; a worktree fora da allowlist pulsa quarentenada. A obra-11, mergeada com recibo, fica verde e quieta — saudável não grita.

Como estrutura — quatro camadas, tudo já existe

Camada 1 · Topologia (dado bruto, local)
O git já sabe o desenho.

git log --all --topo-order --parents + refs + git worktree list, por repo. É exatamente o que o GitKraken lê — zero invenção, zero dependência externa.

Camada 2 · Identidade (ledger)
Cada commit tem um rosto.

O Atlas já carimba quem fez o quê (✦ fable · ◆ codex · ● você · ▲ autônomos) via traces e recibos no ledger. O avatar do GitKraken vira o glifo do agente — e clicar nele abre a proveniência: a SUA frase que originou o commit.

Camada 3 · Lei (canon → rules engine)
As regras que hoje moram em doc viram sinal visual.

main-only pétreo (atlas-server), allowlist de worktrees, "obra tem que voltar à main em N dias", branch órfã, drift de espelho. Cada regra do canon vira um verificador que anota o grafo — com o nome da regra, não um erro genérico.

Camada 4 · Julgamento (a ponte para a Nova Era)
Violação não é alerta — é decisão. E o mapa vem primeiro.

Desktop e iPhone mostram o MESMO mapa visual; a decisão é folha secundária por cima dele — o quê, a regra citada, dois verbos — e resolver desenha a volta para a main na sua frente, deixando recibo e realimentando o guardrail. Notificação de exceção é modo opcional para quando a confiança existir; enquanto ela não existe, você vê.

Passa no filtro pétreo? 5/5

Composto: cada violação resolvida vira guardrail e memória — o grafo fica mais esperto a cada erro. Antifrágil: mais agentes e mais caos = mais valor; nenhum host ou provider nomeado — a topologia é do git local, o espelho é trocável. Linguagem natural: tocar qualquer nó responde "por que isso existe?" em frase humana. Substitui função: isto é o olho do gestor de engenharia supervisionando uma equipe — a equipe agora é de agentes. Soberania: tudo lido da máquina, regras do canon, recibos no ledger. E honra a lei do visual: o grafo não precisa falar nada — mas se você perguntar, ele responde.
