Atlas Código: todas as telas, todas as evoluções, um plano.

Atlas Código é a camada de governança e operação de código do Atlas — substitui o GitKraken como produto, usa o git como motor. Canon: o Atlas commita e cura sozinho, 24/7, todos na main local; o humano tem veto com recibo, nunca portão de aprovação; host remoto é espelho trocável; a verdade mora no Mac. Esta página é o mapa-mestre: onde cada tela vive, em que estado está, e a ordem exata em que o domínio vira produto.

3 · A evolução E0–E5 — um gate por fase, menos humano por fase

Payloads, comandos e critérios exatos na spec §3. Nenhuma fase inicia sem o gate da anterior provado no device com evidência no OBRA §7.

E0 · concluída ✓
Proposta viva — o contrato visual

Grafo v6 + craft system + cura autônoma encenada. Prova: aa01cfa, E2E zero erro.

E1 · topologia — C22
O grafo lê o git de verdade

GET /api/code/graph (git log --all --topo-order + worktrees, read-only, cache incremental) → casca SwiftUI com a geometria canônica.

Gate: hashes no iPhone = git log no Mac.
E2 · identidade — C23
Cada commit com rosto e origem

author→agente (ledger) + /code/provenance/{hash}: a frase do operador que originou o commit.

Gate: 3 commits reais mostram a frase real; sem trace = estado honesto.
E3 · a lei — C24
Regras do canon anotam o grafo

5 regras iniciais (main-only, allowlist worktrees, obra→main ≤ N, branch órfã, drift) — cada violação já nasce com o plano pronto.

Gate: branch cobaia acende com o nome da regra e some ao resolver.
E4 · autonomia — C25
O Atlas cura sozinho, 24/7

Política por regra (observe→heal), executor com allowlist de ações, step_receipts, undo obrigatório ≥30 dias, regra citada ao agente.

Gate: cobaia curada sem toque humano; undo restaura byte a byte.
E5 · prevenção + a semana
Você vira usuário

Guardrail pre-flight nos agentes; /code/week; notificação opcional OFF por default.

Gate: prevenidas ≥ curadas em 2 semanas; card da semana 100% dado real.

4 · Horizontes H1–H6 — onde nenhum SCM alcança

H1 · blame semântico — prioridade máxima
"Por que esta linha existe?"

linha → blame → commit → trace → a SUA frase. Só o Atlas pode (exige o ledger). GET /code/why?file=&line=. Depende: E1+E2.

H2 · release governado
Do commit ao mundo

build → varreduras → assinatura (slide-to-sign, Nova Era 6) → release_receipt. Depende: E4 + M5/T4.

H3 · a semana da frota
Todos os repos, um olhar por exceção

Agregação multi-repo do /week; drill por repo. Depende: E5.

H4 · review agêntica no grafo
Pareceres por commit

council_review já nasce no servidor (posição por membro, sem veredito inventado); falta decode AtlasCore + seção no grafo. Depende: E2.

H5 · prevenção na origem
A violação deixa de existir

Guardrails compostos antes do erro; métrica: violações/semana → 0. Quieto é a vitória. Depende: E4+E5 maduras.

H6 · perguntar ao código
⌘K e a pílula sobre tudo

Open Brain sobre topologia+ledger+canon; respostas com refs conferíveis. Depende: E1–E3; brilha com H1.

7 · As leis do domínio (violou = rejeitado)

  1. Autonomia > aprovação. Operação nunca espera humano; "Aprovar" para plumbing é proibido; existe observe→heal e undo governado.
  2. Zero dado inventado. Sem fonte real, o elemento não existe (ausente ≠ zero).
  3. Visual primeiro. O mapa em toda superfície; recibo/decisão é folha por cima, nunca substituto.
  4. Estado por exceção. Saudável = silêncio; sem ✓ decorativo.
  5. Um sinal primário por violação (tag com o nome da regra do canon) + um secundário.
  6. Linguagem humana em cima, máquina embaixo do vidro (≤2 toques).
  7. A pílula nunca some — perguntar em linguagem natural em toda superfície.
  8. Decisão humana só para produto, preço e risco. Nunca para operação.
  9. Recibo para todo ato no ledger local, append-only.
  10. main-only pétreo no atlas-server; branch é exceção visível em qualquer repo.
  11. Host é adaptador — GitHub/origin/GitLab trocáveis; a verdade mora no Mac.
  12. Craft system obrigatório (spec §5): sprite de ícones, geometria do midpoint, nós flat, zero filtro SVG, tabular-nums, sem sinais de IA.
