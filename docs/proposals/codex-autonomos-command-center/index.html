Autônomos merece um centro de comando próprio.

Sessões conversacionais terminam. Autônomos mantém missões, instâncias e responsabilidades vivas por dias ou semanas. A interface precisa responder: quantos estão rodando, onde, fazendo o quê, há quanto tempo e com qual prova.

Proposta estrutural · A1
Separação canônica: Session Hub acompanha obras interativas; Autônomos Command Center governa uma frota persistente. Live Activity só acompanha uma missão autônoma quando o operador escolher “Seguir” ou quando houver atenção real.

Dados ilustrativos no protótipo; produção mostra somente telemetria real.
