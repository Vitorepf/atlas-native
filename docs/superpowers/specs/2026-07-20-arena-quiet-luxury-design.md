## Barra

Diferenciação por **cuidado milimétrico**, nunca por efeito.  
Olhar e sentir: feito à mão, com amor — sem chamar atenção.

## Gramática

| Marca | Uso |
|---|---|
| ✦ | vivo / com Atlas |
| ○ | sem Atlas |
| ∥ ※ ⌖ ◷ | fila / alerta / cobertura / próxima |
| › | disclosure |
| Ouro | só estado vivo / progresso / com Atlas |

- Sem caixinhas de ícone, sem SF Symbol de template nas linhas.
- Ritmo: 8 / 12 / 16 / 24 / 32.
- Hairlines em gradiente.
- Fraunces = herói; mono = meta/kicker; sans = linha.
- Ausência = “não medido”, nunca zero.
- Motion: ✦ respira (~2.4s); Reduce Motion = estático.

## Entrega

1. **Mockup HTML** — hub (Agora/Frota/Capac/Motor + idle/concluída) + push
   (Execução/Fila/Alertas/Plano) + detalhes (capacidade/suíte) + folhas (Rodar/Parar).
2. **Pílula agêntica** — em toda superfície operacional; pack muda por ocasião.
3. **Swift** — após OK visual do operador.
