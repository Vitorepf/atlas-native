## Arquitetura (pétrea — operador)

### O que é
- **Área Autônomos** = índice (lista). Não é o agente.
- **Um Autônomo** = unidade soberana com **escopo fechado**: charter, contexto, memória, evolução, decisões, desempenho — **só dele**.
- **Workers** = infra compartilhada por baixo. O humano não escolhe frota.

### Por quê vários Autônomos (não um mega com abas)
Atlas Server + Desktop + Native + empresas + trade num feed só = bagunça e desempenho ruim. Isolamento de intenção = isolamento de contexto = foco rápido.

### Exemplos
| Autônomo | Escopo fechado |
|---|---|
| Agente iOS Dinheiro | produto financeiro no iPhone |
| atlas-native | casca nativa — não cuida de Server/Desktop/empresas |
| Empresa Aurora · 24/7 | operação daquela empresa |
| Trade · descoberta | estratégias financeiras |

## Papéis

### Humano
1. Criar / abrir um Autônomo  
2. Ver o que **ele** fez (evolução isolada)  
3. Julgar só o que pede você  
Não programar. Não operar frota. Não misturar feeds.

### Agente (dentro do Autônomo)
Evoluir 24/7 só no charter. Pedir julgamento quando travar. Trabalho saudável = evolução/digest, não spam.
